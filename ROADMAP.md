# Roadmap

Shoppen is pre-alpha. Phases are goals, not promises.

## Phase 0 - Interface study & spec
- [ ] Study public docs and our own dev store (clean-room, see `docs/legal/clean-room.md`)
- [ ] Write specs in our own words (`docs/spec/`)
- [ ] Record request/response pairs and build a conformance test suite

## Phase 1 - MVP core
- [ ] Products, variants, collections
- [ ] Inventory (single location)
- [ ] Customers
- [ ] Cart
- [ ] Stripe checkout
- [ ] Orders
- [ ] Basic admin
- [ ] Default theme
- [ ] **Done when:** one product can be sold end-to-end

## Phase 2 - Compatibility
- [ ] Liquid Online Store 2.0 themes
- [ ] Ajax Cart API
- [ ] Storefront and Admin GraphQL subsets
- [ ] Webhooks with HMAC signatures
- [ ] OAuth apps
- [ ] **Done when:** the conformance suite is green

## Phase 3 - Advanced commerce
- [ ] Discounts
- [ ] EU VAT / OSS
- [ ] Shipping zones
- [ ] Multi-currency
- [ ] Multi-language
- [ ] Gift cards
- [ ] Refunds and returns
- [ ] Multi-location inventory
- [ ] French carriers (Colissimo, Mondial Relay)

## Phase 4 - Ecosystem
- [ ] Visual theme editor
- [ ] Metafields and metaobjects
- [ ] App platform
- [ ] CLI: theme dev / push
- [ ] One-click migration from Shopify

## Phase 5 - Production
- [ ] Performance
- [ ] Security hardening
- [ ] GDPR tooling
- [ ] Observability
- [ ] Docker Compose and Helm charts
- [ ] One-click deploy templates
- [ ] Documentation site

## Later
- [ ] "Shoppen Cloud": a hosted offer
