# Security Policy

ShopMe is pre-alpha and not yet intended for production use. We still take security reports seriously.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting
(repository **Security** tab, "Report a vulnerability"). Include steps to reproduce, affected
versions/commits, and impact. We aim to acknowledge reports within 5 working days.

## Scope

In scope: code in this repository. Out of scope: third-party services, and any store or system you do not own.
Do not test against stores that are not yours.

## Secrets

Never include real credentials in reports, issues, or pull requests.
